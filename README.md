## 🎯 设立宗旨

去除 AI 味的关键不是被动删词，而是主动为模型注入鲜明的文风与语感。

**真人口吻（Human Tone）** 总结了面向社交平台、技术长文与随笔写作的文风参数集：
- **绝对禁令清单**：零引号、彻底封杀对仗辩论腔（“不是……而是……”）、剔除自媒体浮夸词；
- **大师语感蒸馏**：野生黑客流、架构师克制流、极简探针流等成熟音色模板；
- **大白话平铺陈述**：让文字像朋友当面聊天一样自然流淌。

---

## 🎙️ 核心音色预设库

1. **野生黑客流（Street Hacker）**：直率、干脆、单段单句、极简清单；
2. **架构师克制流（Architect Deep Dive）**：沉稳、分寸感、底层机制与精准算账；
3. **极简探针流（Sharp Probe）**：大开大合直击终极困惑，把舞台留给评论区。
